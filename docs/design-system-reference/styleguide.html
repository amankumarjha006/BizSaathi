Typography

Source Serif 4 carries voice, Public Sans carries work, IBM Plex Mono carries amounts and IDs, and Noto Devanagari is a first-class fallback rather than an afterthought — "Saathi" is Hindi, and the product is built for Indian small businesses.

05 — Rules

Usage principles

The rules that keep the system coherent as more surfaces get built.

Do

  • Use --accent for the single primary action on a screen.
  • Reserve --secondary (marigold) for highlights and money-on-track states.
  • Use status colors only for status, never for decoration.
  • Set money in the display serif with tabular figures.
  • Keep body copy at --text-base; use --text-sm for supporting text.

Don't

  • Don't add a gradient hero or a second brand color.
  • Don't use the accent for destructive actions — that's --danger.
  • Don't pill every container; pills are for status chips.
  • Don't set body copy below --text-sm.
  • Don't rely on color alone — pair status with a label or icon.
